# Exer -- Terminal multipl[exer]

The simplest possible terminal multiplexer with minimal yet useful features. Because I want a simple, fast, easy to configure and lightweight tool.

My attempt to learn Odin and do something useful.

**Disclaimer**: code would be a garbage until I understand what the terminal multiplexer consists of. The optimizations and refactor will be later as they always do.

## Run

Build and run:

```bash
odin build . && ./exer
```
